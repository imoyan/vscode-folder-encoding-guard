# 文字コード・改行チェック

フォルダーごとの文字コードと改行を確認するVS Code拡張機能を、小さなPRで段階的に実装・レビューするリポジトリです。

現在は開発準備段階です。インストール可能な拡張機能はまだ提供していません。

## 追加する順序

1. 文字コードルールの判定と単体テスト
2. 文字コード・改行の検査
3. 上限付き読み込みと比較基準
4. VS Code上の表示と設定操作
5. 変換・バックアップ・復元

各PRでは対象の機能、検証結果、未対応範囲を明記します。

## 開発と検証

Node.js 22以降で `npm ci`、`npm run check`、`npm test` を実行します。

実装済みの基盤を以下に追加していきます。VS Codeへの組み込み、ユーザー操作としての検査・変換・復元は後続PRで追加します。

- 文字コードルールの入力検査・優先順位・パス正規化

- 処理の直列化・連続要求の集約とファイルサイズ上限
