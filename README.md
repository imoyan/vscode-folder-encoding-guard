# 文字コード・改行チェック

フォルダーごとの文字コードと改行を確認するVS Code拡張機能を、小さなPRで段階的に実装・レビューするリポジトリです。

現在は開発準備段階です。インストール可能な拡張機能はまだ提供していません。

## 追加する順序

1. 文字コードルールの判定と単体テスト
2. 文字コード・改行の検査
3. 上限付き読み込みと比較基準
4. VS Code上の表示と設定操作
5. 変換・バックアップ・復元

各PRでは対象の機能、検証結果、未対応範囲を明記します。

## 開発と検証

Node.js 22以降で `npm ci`、`npm run check`、`npm test` を実行します。

この段階では、ルールの入力検査、先頭一致による優先順位、パス区切りの正規化、フォルダー名のglobエスケープを扱います。ファイルの読み書きやVS Codeへの組み込みは後続PRで追加します。
