## 生成プロンプト

Use case: logo-brand. Create one polished square application icon for a VS Code extension that checks text file character encoding and newline formats. A clean, bold flat vector-like mark, readable at 48px: a single document silhouette containing a large simple 'A' glyph and a prominent bent return/newline arrow symbol. Small check accent integrated naturally into the document, not another badge layer. Professional developer utility aesthetic, high contrast, restrained cool blue/teal palette, simple geometry, generous margins, centered on a solid square dark background. No words or product name, no extra symbols, no mockup, no multiple variants, no fine detail, no gradients or 3D effects. Output a finished square icon asset.
